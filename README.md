Blackjack Table Management & Simulation Platform

A Java backend project focused on simulating and managing Blackjack table operations through a structured domain model.

Current status: Sprint 1 — Card & Deck foundation completed.

Current functionality:

Card creation
52-card deck generation
Deck shuffling
Drawing cards

Roadmap:
Player → Game → Table → Blackjack Rules → Spring Boot → REST API → PostgreSQL → Backoffice → Real-time communication
